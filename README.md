# 153어닝 Shoots 자동생성기

153어닝 × AWNEX의 **숏폼(Shoots) 영상**을 브라우저 안에서 자동으로 만들어 주는 단일 HTML 도구.
사진과 정보만 넣으면 브랜드 규칙에 맞춘 **대본 + 세로 영상(.webm) + 게시용 문구·해시태그**가 한 번에 나옵니다.

> 유튜브 쇼츠 / 인스타 릴스 / 틱톡용 9:16 세로 영상.
> 모든 처리는 **브라우저 안에서** 이뤄지며, 사진·영상은 서버로 전송되지 않습니다.

## 파일

```
/
├── index.html   # 도구 본체 (단일 파일, 그대로 가비아 웹 루트에 업로드)
└── README.md
```

의존성 없음. `index.html` 하나만 열면 바로 동작합니다. (Pretendard 폰트만 CDN에서 불러오며, 실패 시 시스템 한글 폰트로 자동 폴백)

## 쓰는 법 (4단계)

1. **영상 종류 고르기** — 목적에 맞는 템플릿 1개 선택
   - 🔀 시공 전후 / 🌪️ IoT 태풍 / ☂️ 제품 소개 / ⭐ 고객 후기 / 📍 지역 홍보 / 🎉 이벤트
2. **정보 입력** — 어닝 종류·지역·업종·강조 포인트·영상 길이(8~45초). 비워도 됩니다.
3. **사진 넣기(선택)** — 시공 전/후·제품·현장 사진을 순서대로. 없으면 브랜드 컬러 카드로 대체.
   배경음악(mp3/m4a)도 선택 첨부 가능(**저작권 확인된 파일만**).
4. **대본 자동생성 → ▶ 미리보기 → 🎬 영상 만들기 → ⬇ 저장**
   장면별 자막은 직접 수정할 수 있고, 게시 제목/본문/해시태그는 복사 버튼으로 바로 가져갑니다.

## 자동 적용되는 153어닝 브랜드 규칙

- **3초 룰** — 첫 장면 훅으로 시선을 즉시 잡습니다.
- **손실회피 프레임** — "이대로 두실 건가요?", "태풍에 찢어진 어닝…" 식 공포/손실 프레임.
- **CTA 압축** — 모든 영상이 `사진 한 장 → 30분 견적 → 전화/카카오` 한 갈래로 끝맺음.
- **금지어 자동 차단** — 최저가 / 무조건 / 100% / 업계 1위 등을 감지해 자동 순화하고 경고 표시.
- **디자인 시스템 준수** — 앰버(#E8530E)는 CTA·라벨에만, 그래파이트 배경, Pretendard.
- **신뢰 배지** — 31년 차양 전문 · 서울·경기 500+ 시공 · 정부조달 · 1년 무상 A/S.
- **해시태그 자동 구성** — 기본 + 어닝 종류 + 지역/업종 태그(최대 15개).

## 결과물

- **영상**: 720×1280(9:16), 30fps. 브라우저가 지원하면 **`.mp4`(H.264)로 저장(인스타그램·모바일 호환)**, 미지원 시 `.webm` 폴백. 유튜브 쇼츠·릴스·틱톡에 그대로 업로드 가능.
  - 사진 Ken Burns 줌/팬, 자막 등장 애니메이션, 진행 바, 로고 워터마크, 앰버 CTA 엔드카드 포함.
- **게시 패키지**: 제목 · 본문/설명(연락처 포함) · 해시태그(복사 버튼).

## 기술 메모

- 렌더링: Canvas 2D → `canvas.captureStream(30)` → `MediaRecorder`.
  - 코덱 우선순위: `mp4(H.264/AAC)` → 미지원 시 `webm(VP9/VP8 + opus)`.
- 배경음악은 `AudioContext` → `MediaStreamAudioDestinationNode`로 영상에 믹싱.
- **권장 브라우저: 최신 Chrome.** (mp4 녹화는 Chrome 최신 버전에서 지원)

가비아 등 정적 호스팅에 `index.html`을 업로드하면 끝. (별도 빌드·백엔드 불필요)
